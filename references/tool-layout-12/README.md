# 工具电商图文排版 · 12 张品牌参考

图文图层「智能排版」的六种版式据此而来（`layer_compose.py`）。本包整理自用户提供的参考页，原图来自 HOTO、Fanttik、Wera 和 Bosch Professional 的官方网站。逐条信息见 `references.csv`：编号、版式、品牌、来源页、原图链接、构图说明、借鉴与注意事项，以及本应用中对应的版式。

## 使用与版权

本包只收录来源链接和文字分析，不含图片文件或缩略图。版权归各品牌所有；整理这些链接不代表获得了商用许可，原图中的规格、认证和性能数据也不能用到其他产品上。来源可能更新，也可能限制访问；访问日期为 2026-11-14。点评是设计建议，不是转化率研究；这些版式也没有在欧洲市场验证过。参考图只用于研究构图，正式作图请用自己的产品与授权素材独立完成。

## 共同原则

一张图只回答一个购买问题：一个短标题，一个主要视觉，最多三条短说明。底色用浅灰或深灰，品牌色只用来强调关键数字。所有数字和功能表述都要先核实。横幅需要重新适配成方图或竖图，不能直接等比缩小。

## 应用里的六种版式

| 版式 | 对应参考 | 怎么排 | 适合 |
|---|---|---|---|
| 左右分区 `split` | 01、05 | 一侧文字栏：标题，下面接一到两个关键数字或三条要点；另一侧放产品 | 干净的产品图、品牌首屏 |
| 结构标注 `callouts` | 02、07、11 | 产品在一侧，另一侧最多四条说明对齐成一列，用细线连到对应部件 | 钳口、转轴、锁扣、抽屉滑轨等结构 |
| 场景叙事 `scene` | 03、09 | 标题放在场景图最安静的一侧；找不到安静区域时，标题单独占画面上方一条 | AI 生成或带道具的使用场景 |
| 卡片网格 `cards` | 04、06 | 产品放在大卡片里，最多三张小卡片各写一个要点或数字 | 卖点总览、多功能产品、套装 |
| 单点卖点 `spotlight` | 08 | 标题、产品，下方一条品牌色带，承载一到两个关键数字 | 一个购买问题，需要有数字 |
| 规格清单 `specs` | 10 | 产品下方列一排规格，或一排尺寸（如扳手 8–24 mm） | 套筒、批头、扳手套装 |

参考 12（系列对照）要把两组产品并排比较，一张合成图只有一张渲染图，因此没有对应版式。工具箱系列或不同套装需要对照时，请分别渲染后另行排版。

## 应用遵守的几条规则

- **先排文字，再放产品。** 版式先给文字留出位置，再把产品放进剩下的空间，文字永远不压在产品上。
- **产品永远完整。** 照片可以裁切，但不会扩边，也不会裁掉产品的任何部分。照片填不满分到的区域时，会作为一张带圆角的图片单独放在画面里。
- **影棚图与其他图片分开处理。** 平整的影棚背景（边缘一圈颜色一致）可以无缝延伸到同色画布上。地面打光造成的渐变、场景照片或 AI 生成的照片，都保留硬边。
- **文字颜色保证可读。** 小号灰字与画布的对比度至少 4.5:1，彩色数字至少 3:1。产品自身的颜色读不清时，改用墨色。
- **数字只来自用户。** 版式中出现的数字都必须来自用户写下的规格或项目资料；AI 给出的其他数字一律去掉，并在提示里说明。
- **没显示的内容会说明。** 某个版式没有显示的要点、数字或规格，会列在提示里，方便改用其他版式。
- **图标：** 先在随应用附带的开源图标库中查找（Lucide ISC、Tabler MIT），也可以在线查找，但只取 MIT、ISC、Apache-2.0 授权的图标库。都没有合适的，再由 AI 画一个，并由视觉模型核对。每个图标的来源和授权都随图层保存。
