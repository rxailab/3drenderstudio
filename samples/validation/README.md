# 样例资产的实际验证

执行环境：Blender 5.0.1，本机 `D:\blender\blender.exe`。6 个样例均通过当前 `blender/worker.py` 的实际导入和分析，输出见各子目录 `result.json` 与汇总 `summary.json`。本记录是资产和执行层检查，不替代应用界面端到端验收。

| 样例 | 实测结果 |
| --- | --- |
| 哑光按压瓶 GLB | 8 网格，细长特征为 true，保留 4 材质与文字几何；无缺图、无退化面 |
| 金属收纳盘 GLB | 1 网格，扁平特征为 true；合并接缝后封闭拓扑、无退化面 |
| 厚壁玻璃杯 GLB | 1 网格，透射材质识别成功；合并接缝后封闭拓扑、无退化面 |
| 混合材质包 GLB | 43 网格，父层级保留，内嵌帆布贴图可读，无退化面 |
| 混合材质包 OBJ/MTL | 43 网格，`textures/canvas-weave.png` 相对路径解析成功，无缺图、无退化面 |
| 侧放且缺贴图金属盘 OBJ | 模型可导入；准确报告 `brushed-steel-missing.png` 缺失，实际单位未知 |

旋转体、倒角硬表面导出为 GLB 后，UV/法线接缝会拆分顶点。分析器现在仅在临时网格中合并同坐标接缝再判断拓扑；保留 raw_non_manifold_edges，且不修改原始资产。金属盘与玻璃杯由此不再被误报为开放结构。薄纸标边界和少量文字装饰仍有开放边，已由检查结果标出。

瓶身首版标签板与圆柱相交，曾在预览中显示成两条白边。已将标签改为贴合圆柱的曲面。随后 4K 检查发现大字 M/A 仍存在笔画遮挡：细长化时使用文字对象的局部轴缩放，导致已旋转文字的曲面位移与瓶身不同步。现改为全局 XY 矩阵缩放，并在曲面贴合前细分文字三角面。最终 `fixed-bottle-preview/fixed-bottle-preview.png` 为 10° 正面真实 512×512 Cycles 渲染，已目视确认 MORA 四字完整（OPTIX，NVIDIA GeForce RTX 3070 Laptop GPU）。PNG 与同尺寸 JPG、可复现 Blender 工程及执行结果均已输出。该文件是执行层单镜头检查，不能计入通过正常应用界面进行的上传/下载验收；之前项目中保存的原始模型和渲染不被覆盖。

样例中无绑定或动画，机械运动与柔性状态能力未由这些资产验证。GLB 金属各向异性未导出；要检验拉丝方向应使用应用内拉丝金属预设。所有资产均自制 CC0，来源见上级目录 LICENSE.txt。
