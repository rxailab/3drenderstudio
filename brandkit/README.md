# 品牌模板（T01–T13）

套图的版式。每个模板是一页按规则排版的 HTML/CSS/SVG：任务（JSON）注入为 `window.JOB`，页面自己计算布局。之后共享运行时 `engine/runtime.js` 测量真实 DOM，把 QA 记录写回页面，由 `brandkit_render.py` 通过无窗口的 Chrome / Edge 读取。

| 文件 | 内容 |
|---|---|
| `templates/T0x.html` | 模板源码（选定方向），`<!--INJECT-->` 处注入任务 |
| `templates/T0x.json` | 模板记录：参考映射、色板与间距、元素、文字层级 |
| `engine/runtime.js`、`engine/base.css` | 共享运行时（定位、裁切、引线、版面测量）和基础样式 |

来源：为本项目特制的品牌模板设计系统。v34 起，T01–T06、T08、T12 按亚马逊参考图重做（见项目 README），共享运行时新增字体加载等待、[[强调]] / {胶囊} 标记、遮罩、图标、参数块、圆形放大框、直角引线、统计块和英文页中文检查（`lang_mismatch`）；字体与图标由 `brandkit_assets.py` 下载到 `brandkit/vendor/`。早先的改动：安全边距检查只在有演示水印条时才为它留出 40px；T12 的任务可以用 `compact: true` 换用模板自带的较小标题字号，供长中文标题在窄栏里不被拆开时使用；T04 信息带各列顶部对齐（原来各列分别居中，带大数字的一列标签会比其他列高）；T02 的羽化边写进 `data-feather`，运行时把它记入 QA（`feather`），供渲染端检查特写框是否切过小部件。

由套图流程 `brandkit_set.py` 使用。各模板读取的任务字段，见 `brandkit_set.jobs_for`。

| 模板 | 用途 | 套图里 |
|---|---|---|
| T12 | 海报主图（场景 + 标题带，无场景时纯色版） | 自动 |
| T01 | 浅底功能标注（引线指向部件） | 自动 |
| T03 | 主体 + 细节栏 | 自动 |
| T13 | 多姿态展示（同一视角、同一比例下产品的 2–3 个活动状态，如闭合 / 打开；由姿态 agent `articulation.py` 识别） | 自动（识别出 2 个以上姿态时） |
| T02 | 深色细节特写 | 自动 |
| T04 | 场景 + 参数带 | 自动 |
| T08 | 使用场景组图 | 自动 |
| T06 | 尺寸图 | 自动 |
| T05 | 包装清单 | 自动 |
| T07 | 模块系统 | 需要模块层级，不生成 |
| T09 | 同条件对比 | 需要对比证据，不生成 |
| T10 | 接口与连接 | 需要连接关系，不生成 |
| T11 | 同系列变体 | 需要其他型号的模型，不生成 |
